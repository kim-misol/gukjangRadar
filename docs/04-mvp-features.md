# STEP 4. MVP Feature List

범례: **M**=Must(V1) · **S**=Should(V1.1) · **C**=Could(V2) · **W**=Won't

## A. 데이터 수집
| ID | 기능 | 등급 | 비고 |
|---|---|---|---|
| A1 | 뉴스 수집 (RSS + 제휴 API) | M | 제목·요약·링크만 저장, 본문 미보관 (D5) |
| A2 | 뉴스 중복 제거 / 클러스터링 | M | SimHash + 임베딩 코사인 |
| A3 | 상장사 마스터 (KOSPI/KOSDAQ 전종목) | M | 티커·정식명·약칭·영문명·구 사명 |
| A4 | 기업 별칭·계열 관계 (OpenDART) | M | 계열회사·최대주주 → `AFFILIATION` 엣지 |
| A5 | 시세 스냅샷 (지연) | M | KIS Open API, 5분 배치 |
| A6 | 산업/테마 사전 | M | 초기 수기 300~500개 |
| A7 | 공급망 관계 DB | S | 초기엔 사전 + 사업보고서 수기, 이후 자동화 |

## V1 완성 정의 (Definition of Done)
1. 오전 7시~오후 8시, 5분 주기로 뉴스가 들어와 연결이 자동 생성된다.
2. 임의의 뉴스 카드에서 그래프를 열면 경로와 근거가 보인다.
3. 골든셋 40케이스 중 38개 이상 통과.
4. 환급 종목(존재하지 않는 티커) 0건.
5. 키워드 알림이 실제 푸시로 도착한다.
6. 모든 화면에 고지 문구가 있고 금지어 린터가 통과한다.
