# STEP 2. User Journey

## 핵심 루프
```
이슈 인지  →  앱 열기  →  뉴스 카드  →  연결 그래프  →  "아 그래서 저게 올랐구나"
                                              ↓
                                        공유 / 키워드 알림 등록
                                              ↓
                                    다음 이슈 때 푸시로 재진입
```
리텐션 엔진은 **알림**, 획득 엔진은 **밈 공유**, 이해 엔진은 **그래프**다. 셋 중 하나라도 빠지면 성장이 멈춘다.

## J1. 테마 트레이더 (세그먼트 A) — "태풍 왔다"
| # | 상황 | 사용자 행동 | 시스템 | 화면 |
|---|---|---|---|---|
| 1 | 오전 8:40, 태풍 뉴스 | 푸시 탭 (`"태풍" 키워드 뉴스 발생 · 연결 4건`) | 알림 페이로드에 top1 연결 포함 | Push |
| 2 | | 뉴스 카드 확인 | AI 요약 3줄 + 연결 종목 4개 | `/news/[id]` |
| 3 | 왜 노루페인트? | 그래프 탭 | 경로 렌더 `태풍 노루 → 노루 → 노루페인트` | `/news/[id]` 그래프 |
| 4 | 진짜 관련 있나? | 사업 연관성 배지 확인 | `business_relevance: 12 (낮음)` + 근거: "도료 제조업, 태풍 관련 매출 비중 공시 없음" | 종목 카드 |
| 5 | 시장은? | 시장 반응 확인 | 거래량 +183%, 등락 +7.2% (지연 시세, 기준 시각 표기) | 종목 카드 |
| 6 | | 다른 태풍 때는? | 과거 유사 사례: 2023 태풍 카눈 당시 동일 패턴 | `유사 사례` 섹션 |
| 7 | | "태풍" 키워드 알림 유지 | | |

**핵심 순간(aha)**: 4번. "관련주라는데 실제로는 상관없음"이 명시되는 순간 신뢰가 생긴다.

## J2. 관찰형 (세그먼트 B) — "이거 왜 올랐어?"
| # | 행동 | 시스템 |
|---|---|---|
| 1 | 홈에서 `급등 종목 ↔ 뉴스` 섹션 확인 | 오늘 급등 상위 20종목을 역방향으로 뉴스와 매칭 |
| 2 | 종목 탭 | `/stock/[ticker]` — 오늘 이 종목에 걸린 연결 전부 |
| 3 | 연결 없음인 경우 | **"설명 가능한 뉴스 연결을 찾지 못했습니다"를 그대로 노출** (억지로 만들지 않는다 → R1) |

> 역방향 탐색(종목 → 뉴스)은 순방향만큼 중요하다. B 세그먼트의 진입점이자, 우리 엔진의 재현율을 자가 측정하는 지표가 된다.

## J3. 밈 소비자 (세그먼트 C) — "이거 봐라 ㅋㅋ"
| # | 행동 | 시스템 |
|---|---|---|
| 1 | 트위터/커뮤니티에서 공유 이미지 유입 | OG 이미지 = 오늘의 억지 관련주 랭킹 카드 |
| 2 | `/discovery` 랜딩 (로그인 불필요) | 밈 랭킹 3위까지 + 연결 강도/밈력 게이지 |
| 3 | 공유 | 카드 이미지 서버사이드 생성(`@vercel/og`) |
| 4 | 전환 | "이런 연결 미리 알고 싶다면 → 키워드 알림" CTA에서만 로그인 요구 |

**로그인 벽은 알림 등록 시점에만 세운다.** 조회는 전부 익명 허용 → 바이럴 계수 유지.

## 최초 사용자(FTUE)
1. 온보딩 3장: ①"우리는 추천하지 않습니다" ②연결 유형 5종 ③알림 설정
2. 관심 키워드 3개 프리셋 제안(반도체 / 태풍·기상 / 밈)
3. 알림 권한은 **2회차 방문 때** 요청 (첫 방문 즉시 요청 시 거절률 급증)

## 이탈 지점과 대응
| 이탈 | 원인 | 대응 |
|---|---|---|
| 홈 진입 후 3초 이탈 | 오늘 뉴스가 지루함 | 홈 최상단은 항상 "오늘의 억지 관련주"(엔터테인먼트 우선) |
| 그래프 안 누름 | 그래프인지 모름 | 카드에 경로를 **미리보기 텍스트**로 노출 `태풍 노루 → 노루 → 노루페인트` |
| 알림 끔 | 너무 잦음 | 키워드당 일 최대 3회, 연결 강도 임계값 이상만 |
