# STEP 1. PRD — 국장레이더

## 1. 한 줄 정의
**뉴스에서 종목을 발견하는 앱.** 오를 종목이 아니라, 뉴스와 연결된 종목과 그 연결 방식을 보여준다.

## 2. 문제
국내 개인투자자는 이슈가 터졌을 때 "이거 관련주 뭐임?"을 커뮤니티·단톡방·유튜브에서 찾는다. 문제는:

| 문제 | 현상 |
|---|---|
| P1. 근거 없음 | "○○ 관련주"라는 말만 있고 왜 관련인지 설명이 없다 |
| P2. 구분 없음 | 실제 매출 연관 기업과 이름만 같은 기업이 같은 목록에 섞인다 |
| P3. 늦음 | 이미 3일 상한가 간 뒤에 목록이 돈다 |
| P4. 의도 | 목록을 뿌리는 사람이 이미 들고 있다 |

국장레이더는 P1, P2를 정면으로 푼다. **연결의 종류와 근거를 드러내는 것**이 제품이다.
P3(속도)은 알림으로, P4(의도)는 "우리는 추천하지 않는다"는 포지셔닝으로 회피한다.

## 3. 왜 지금
- 이슈 → 이름 유사 종목 급등이 국장에서 **반복 재현되는 패턴**이 되었다(투자자들이 이미 이 게임을 인지하고 있다).
- LLM이 등장하면서 "노루(태풍) ↔ 노루페인트"처럼 **문자열이 아니라 의미 단위**의 연결 탐색이 가능해졌다.
- 기존 관련주 서비스는 여전히 산업 분류표 기반이라 ④이름·⑤밈 레이어를 다루지 못한다.

## 4. 타깃
| 세그먼트 | 비중 목표 | 니즈 |
|---|---|---|
| A. 테마 트레이더 (20~40대, 국장 단타) | 50% | 이슈 발생 시 후보군을 빠르게 |
| B. 관찰형 투자자 | 30% | "왜 저게 올랐지?"의 사후 해설 |
| C. 밈 소비자 (투자 안 함) | 20% | 웃긴 연결고리 공유 → 바이럴 유입 |

C가 A로 전환되는 구조. C를 무시하면 성장 채널이 없다.

## 5. 핵심 차별점 = 연결 레이어 5종 + 그래프
| 레이어 | connection_type | 예 |
|---|---|---|
| ① 직접 | `DIRECT` | AI 반도체 수요 ↑ → SK하이닉스 |
| ② 공급망 | `SUPPLY_CHAIN` | 엔비디아 신제품 → HBM → 장비 → 소재 |
| ③ 테마 | `THEME` | 폭염 → 냉방/전력/빙과 |
| ④ 이름 | `NAME_MATCH` | 태풍 노루 → 노루페인트 |
| ⑤ 밈 | `MEME` | 원희 → 원익 |

보조 유형: `AFFILIATION`(계열), `PERSON`, `PRODUCT`, `LOCATION`, `EVENT`, `KEYWORD`.
전체 정의는 `spec/types.ts`의 `ConnectionType`.

**진짜 제품은 목록이 아니라 그래프다.** 뉴스를 누르면 `태풍 노루 → 노루 → 노루페인트 → 노루홀딩스 → 페인트 → 건설·도료`가 노드/엣지로 펼쳐지고, 각 엣지에 근거가 붙는다. 목록형 UI는 그래프의 요약본일 뿐이다.

## 6. 제품 원칙
1. **연결을 숨기지 말고 등급을 매겨라.** 억지 연결을 감추는 게 아니라 "억지"라고 라벨을 붙여서 보여준다.
2. **설명 없는 종목은 없다.** 모든 카드에 경로와 한 줄 근거.
3. **점수는 두 축.** 사업 연관성 축과 화제성(키워드/밈) 축을 분리한 2차원 배치. 하나의 랭킹으로 뭉개지 않는다.
4. **추천하지 않는다.** 정렬 기준조차 "상승 기대순"이 아니라 "연결 강도순 / 시장 반응순".
5. **틀리면 틀렸다고 한다.** 사후에 연결이 부정되면 카드에 정정 표시(`disputed`).

## 7. 법적 경계 (설계 제약, 중요)
현재 확인된 사실 관계:
- 유사투자자문업은 **대가를 받고 불특정 다수에게 특정 종목에 관한 조언**을 할 때 금융위 신고 대상이다.
- **양방향 채널**(유료 회원의 개별 질문에 답하는 구조)은 유사투자자문 범위를 넘어 **투자자문업 등록** 이슈로 간다. 위반 시 형사 처벌 대상.

→ 설계 결론 (개발 시 반드시 지킬 것):
| 결정 | 내용 |
|---|---|
| D1 | V1은 **무료**로 출시한다. 유료화(PRO) 전에 유사투자자문업 신고 여부를 변호사와 확정한다. 과금 코드는 붙이되 기능 플래그로 꺼둔다. |
| D2 | "STEP 8. 사용자 제보" 기능에서 **AI가 사용자 질문에 종목을 답하는 형태**는 양방향 개별 조언으로 읽힐 수 있다. V1에서는 사용자가 던진 **키워드를 공개 피드의 탐색 대상으로 큐잉**하고 결과를 **전체 공개**로만 노출한다(1:1 응답 금지). |
| D3 | 모든 화면 하단 고정 문구: "국장레이더는 뉴스와 종목의 연결을 보여주는 정보 서비스이며 투자 추천·자문이 아닙니다. 투자 판단과 그 결과는 이용자 본인에게 귀속됩니다." |
| D4 | 금지어 린터를 CI에 넣는다(R5). 카피·프롬프트 출력 모두 검사. |
| D5 | 뉴스 본문은 저장·재배포하지 않는다. **제목 + 3문장 이내 AI 요약 + 원문 링크**만. 이미지 핫링크 금지. RSS/제휴 API 우선. |

> 이 문서는 법률 자문이 아니다. 유료화·알림 상용화 전에 자본시장법 전문 변호사 검토를 받을 것.

## 8. 성공 지표
| 단계 | 지표 | 목표(출시 3개월) |
|---|---|---|
| 발견 품질 | 연결 카드 "이해됐다" 피드백 비율 | ≥ 70% |
| 정확도 | 골든셋 회귀 통과율 | ≥ 95% |
| 안전 | 환각 종목(존재하지 않는 티커) 노출 | **0건** |
| 참여 | D7 리텐션 | ≥ 25% |
| 바이럴 | "오늘의 억지 관련주" 공유 수 / DAU | ≥ 3% |
| 속도 | 뉴스 발행 → 연결 카드 노출 p50 | ≤ 5분 |

## 9. 안티 골
- 매매/계좌연동/포트폴리오 — 하지 않는다.
- 수익률 백테스트로 "이 전략 수익률 N%" 표기 — 하지 않는다(투자권유로 읽힘).
- 종목 토론방 — 하지 않는다(관리 비용 + 시세조종 통로).
- "AI가 고른 오늘의 종목 TOP5" — 절대 하지 않는다. 이건 다른 제품이다.
