# 화면 디자인 가이드 — "종이신문" 컨셉 (시안 D)

작성: 2026-08-21 (Claude Design 캔버스 세션에서 정리)

## 배경

`/design`으로 국장레이더 메인 대시보드(이슈 피드) 톤 방향 5가지를 스케치함
(A 다크 터미널, B 라이트 핀테크, C 에디토리얼 뉴스룸, D 진짜 종이신문, E 9시 저녁뉴스).
그중 **D(종이신문)** 를 채택해 실제 클릭 가능한 프로토타입(웹 1280px + 모바일웹 390px)으로
발전시켰음. 필터·정렬·검색·이슈 확장·스크랩 전부 실제 동작 확인 완료(Playwright로 클릭 검증).

캔버스 링크(작성 당시): https://claude.ai/code/artifact/6e838ab8-8109-4e4c-8f81-e7b2db7bc444
— **W6(2026-08-21) 확인 결과 이 링크와 `design/main-desktop.dc.html`/`design/main-mobile.dc.html`
원본 소스는 더 이상 존재하지 않는다** (`git log --all`에도 없고, 이 계정의 Artifact 목록에도
없음 — 캔버스가 삭제됐거나 다른 세션/계정에서 만들어진 것으로 보인다). 원본 마크업을 다시
볼 방법이 없으므로, 새 화면을 만들 때는 **아래 토큰 표 + 컴포넌트 패턴 설명이 유일한
기준**이다 (실제 재사용 사례: `apps/web/app/globals.css`, `apps/web/tailwind.config.ts`,
`apps/web/components/`, docs/15-build-order.md W6 기록).

## 톤 & 컨셉

실제 종이신문 지면 레이아웃을 웹 UI로 재해석. 이슈 피드를 "오늘자 지면"처럼 보여주고,
헤드라인을 클릭하면 실제 신문 기사를 읽듯 2단 조판 + 드롭캡으로 확장된다.
헤비유저용 정보 밀도(다크 터미널)나 대중적 밝기(라이트 핀테크) 대신, **신뢰감·저널리즘 톤**을
우선시하는 방향.

## 디자인 토큰

| 용도 | 값 |
|---|---|
| 배경(종이색) | `oklch(0.965 0.006 80)` |
| 본문 텍스트 | `oklch(0.16~0.25 0.006 80)` (거의 무채색, 채도 낮게) |
| 상승(빨강 — 국내 증시 관행, 미국식과 반대이니 주의) | `oklch(0.5 0.19 25)` |
| 하락(파랑) | `oklch(0.42 0.12 250)` |
| 괘선(연한 구분선) | `oklch(0.75~0.8 0.006 80)` |
| 마스트헤드 하단 괘선 | `3px double oklch(0.16 0.006 80)` |
| 헤드라인 / 마스트헤드 서체 | `Noto Serif KR` (세리프, Google Fonts) |
| 본문 / 메타 서체 | `Noto Sans KR` |
| 숫자·코드성 텍스트(HEAT·등락률·시각) | `JetBrains Mono` |
| 리드 문단 드롭캡 | `.lead-para:first-letter` — `font-size: 3.2~3.6em`, `font-weight:900`, `line-height:0.78` |

## 레이아웃 규칙

**데스크톱(1280px 고정 폭)**
1. 상단 메타 행 — 호수 / 날짜 / 부제, 얇은 괘선
2. 마스트헤드 — "국 장 레 이 더" 자간 넓힌 세리프 46px, 하단 KOSPI/KOSDAQ mono 표기, 이중 괘선으로 마감
3. 카테고리 탭 + 검색창 + 정렬 토글 한 줄
4. 3열 그리드(`repeat(3, minmax(0,1fr))`) — 본문은 1~2열(2/3 폭), 사이드바는 3열(1/3 폭)
5. 하단 고지문구

**모바일(390px 폭)**
- 마스트헤드 축소(세리프 28px), 카테고리는 가로 스크롤 칩 행(`overflow-x:auto`)
- 사이드바 없음 — "지금 뜨는 검색어" / "공시속보" 섹션이 이슈 리스트 아래로 내려옴
- 헤드라인 탭 → 같은 화면 안에서 전체 폭 리딩뷰로 전환(별도 페이지 이동 아님)

## 컴포넌트 패턴

- **이슈 카드**: 좌측에 랭크(2자리, mono) + HEAT 점수 세로 스택 → 카테고리 라벨(공시 건은 "· 공시" 접미) + 스크랩 별 아이콘(우측 정렬) → 세리프 헤드라인(리스트 1위만 확대 22px+드롭캡, 나머지 16px) → 요약 1줄 → 관련기업 칩(상승/하락 색상 mono) → 메타 텍스트(뉴스 건수·매체·경과시간, mono)
- **카테고리 탭**: 전체/반도체/2차전지/바이오/건설/금융. 활성 탭 = 세리프 굵게 + 밑줄(데스크톱) / 채움 배경(모바일 칩)
- **정렬 토글**: HEAT순 / 최신순, mono 텍스트, 활성 시 굵게+밑줄
- **검색창**: 제목 + 관련기업명 실시간 부분일치 필터. 사이드바 트렌드 키워드를 클릭하면 그 단어가 검색어로 자동 입력됨(전체 탭으로 리셋)
- **상세/확장 뷰**: 헤드라인 클릭 → "← 목록으로" + 카테고리·HEAT 한 줄 + 큰 세리프 제목 + 관련기업 + 본문(데스크톱은 `column-count:2` 2단 조판, 모바일은 단일 컬럼), 첫 문단 드롭캡
- **사이드바 모듈**: "지금 뜨는 검색어"(클릭 가능, 순위 mono), "공시속보"(정적 리스트) — 둘 다 `border:1px solid` 박스, 상단에 세리프 소제목 + 밑줄

## 데이터 / 카피 규칙

- **상승 = 빨강, 하락 = 파랑** (국내 증시 관행 — 반드시 지킬 것)
- **필수 고지문구**(변경 금지 — `packages/core/src/copy-guard/forbidden-words.ts`의 `SAFE_PHRASES`
  allowlist와 연동되는 문구이므로 그대로 사용):
  > 국장레이더가 제공하는 정보는 투자 추천·자문이 아닙니다. 투자 판단과 책임은 본인에게 있습니다.
- **카테고리 taxonomy**: 반도체 / 2차전지 / 바이오 / 건설 / 금융 (탭에 노출) + 시황(탭 없이 "전체"에서만 노출 — 개별 종목이 아닌 지수·매크로 이슈용)
- 카드 데이터 구조(프로토타입 기준): `category, heat, mins(경과분), title, summary, body(상세 본문), companies[{name, pct}], newsCount, sources[], isDart`

## 인터랙션 (프로토타입에서 실동작 확인됨)

카테고리 필터 · 정렬 전환 · 검색(실시간 필터 + 트렌드 클릭 연동) · 이슈 확장/축소 · 스크랩 토글 —
전부 브라우저에서 클릭까지 직접 확인. 데스크톱·모바일 두 폭 모두 동일 로직으로 검증됨.

## 재사용 방법

새 화면(예: 기업 상세 페이지, 검색 결과 페이지 등)을 디자인할 때:
1. 위 토큰 표의 색상·서체·괘선 값을 그대로 가져다 쓴다.
2. 마스트헤드 + 하단 고지문구는 모든 화면에 공통으로 유지한다(신문 지면이라는 컨셉 정체성).
3. 카드/탭/정렬/검색 같은 반복 요소는 위 컴포넌트 패턴의 구조(레이아웃 순서, 강조 방식)를 그대로 따른다.
4. 데스크톱은 3열 그리드(본문 2/3 + 사이드바 1/3), 모바일은 단일 컬럼 + 하단 스택이라는 기본 골격을 유지한다.
5. 원본 마크업(.dc.html)과 캔버스 링크는 더 이상 존재하지 않는다(§배경 참고) — 실제 구현 예시는
   `apps/web/components/`(특히 `home/`, `layout/`, `ui/`)를 참고한다.
