# STEP 5. 화면별 상세 기능명세

> 타입은 `spec/types.ts`, API는 `spec/openapi.yaml` 참조. 여기서는 **UI 동작과 규칙**만 정의한다.

---
## S1. 홈 `/`
**API**: `GET /v1/home?date=today`

**블록**
1. `MemeRankBlock` — `GET /v1/discovery/meme?limit=3`
   - 각 항목: 순위 메달, `entity → company` 화살표 텍스트, 연결 강도 게이지, 밈력 게이지, 한 줄 AI 코멘트
   - 게이지 2개는 **색이 달라야 한다**(연결=파랑 계열, 밈=주황 계열). 같은 색이면 합산 점수로 오해된다.
2. `NewsClusterListBlock` — 클러스터 5개
   - 카드 구성: 이모지, 헤드라인, 매체 수 배지(`23개 매체`), 발행 시각(상대), **경로 미리보기 텍스트** 최대 2줄, 연결 종목 칩 최대 4개(+n)
   - 칩 색: `business_relevance ≥ 60` 초록 / `30~59` 파랑 / `< 30` 회색. 밈은 회색 + 😂
3. `MoverNewsBlock` — 급등/급락 상위 10, 각 종목에 매칭된 뉴스 1건 또는 "연결 미발견"
4. `RecentConnectionsBlock` — 최근 60분 신규 연결 스트림
5. `DisclaimerBlock` — 고정

**규칙**
- 장 시작 전(08:00 이전)에는 3번 블록을 전일 종가 기준으로 표시하고 `전일 기준` 배지.
- 뉴스 없음(주말/연휴): 최근 3일 아카이브 + "오늘은 조용합니다" 상태.
- 모든 카드 탭 → `/news/[clusterId]`.

## S2. 뉴스 상세 `/news/[id]`
**API**: `GET /v1/news/{id}` (요약·개체), `GET /v1/news/{id}/connections`, `GET /v1/news/{id}/graph`

**섹션 순서**
1. 헤드라인 + 원문 링크(외부 새 탭) + 매체 목록 아코디언
2. `AI 3줄 요약` — 항상 3문장. 원문 인용 20자 초과 금지.
3. `핵심 개체 칩` — 개체 타입별 아이콘. 탭 시 그래프에서 해당 노드 하이라이트.
4. **`ConnectionGraph`** (아래 S3)
5. `연결 종목 리스트` — 기본 정렬 connection_score desc
   - 행: 종목명 / 티커 / `ConnectionTypeBadge` / connection_score / 사업연관성 3단계(높음·보통·낮음) / 거래량 변화 / 밈 뱃지
   - 필터 토글: `사업 연관만` `밈 포함`
6. `AI 한줄평` — 반드시 "가능성"·"관심" 어휘. 금지어 린터 대상.
7. `👍 이해됐어요 / 🤔 억지스러워요` 피드백 (익명 허용, 1인 1회)
8. 고지

**엣지케이스**
| 상황 | 처리 |
|---|---|
| `analysis_status = PENDING` | 1~3만 렌더, 4~6 스켈레톤, 5초 폴링 |
| 연결 0건 | "설명 가능한 연결을 찾지 못했습니다." + 개체 칩은 유지 |
| 정정된 연결 포함 | 해당 행 취소선 + `정정됨` 배지 + 사유 툴팁 |
| 원문 삭제(404) | 카드 유지, 링크 비활성 + `원문 삭제됨` |

## S3. 연결 그래프 `ConnectionGraph` (핵심 컴포넌트)
**API**: `GET /v1/news/{id}/graph` → `{ nodes[], edges[] }`

**렌더**
- 라이브러리: `d3-force` (SVG). 모바일 성능 위해 노드 60개 상한, 초과 시 `connection_score` 하위 절단 + "n개 더보기".
- 레이아웃: 좌 → 우 4레인. `NEWS` | `ENTITY` | `CONCEPT` | `COMPANY`
  - 뉴스는 항상 최좌측 단일 노드, 기업은 최우측. 사용자가 "왼→오른쪽으로 흐른다"를 즉시 이해해야 한다.
- 노드: 타입별 모양(뉴스=둥근사각, 개체=원, 개념=마름모, 기업=사각+티커)
- 엣지: `edge_type`별 색 + 굵기 = `weight`. 미검증 엣지(evidence 없음)는 **점선**.
- 상호작용
  - 노드 탭 → 해당 노드까지의 **모든 경로 하이라이트**, 나머지 20% 투명도
  - 기업 노드 탭 → 하단 시트에 종목 카드(S4 요약본)
  - 엣지 탭 → 근거 팝오버 (`evidence.label`, 출처 링크, confidence)
  - 핀치 줌 / 드래그 팬 / 더블탭 리셋
- 접근성/폴백: `prefers-reduced-motion`이면 force 시뮬레이션 없이 정적 배치. **텍스트 폴백 필수** — 경로를 `A → B → C` 목록으로도 제공(SEO·공유·스크린리더).

**경로 문구 생성 규칙**
경로 라벨은 LLM이 아니라 템플릿으로 만든다(결정론적, 무비용):
```
NAME_MATCH   : "{entity}와 회사명이 일치"
NAME_SIMILAR : "{entity}와 발음/표기가 유사 (편집거리 {d})"
AFFILIATION  : "{a}의 {rel}"          // 지주회사/계열사/자회사
SUPPLY_CHAIN : "{a} → {b} 납품 관계"
THEME        : "{theme} 테마 구성 종목"
DIRECT       : "{entity} 사업을 직접 영위"
```

## S4. 종목 상세 `/stock/[ticker]`
**API**: `GET /v1/stocks/{ticker}`, `GET /v1/stocks/{ticker}/connections?date=`

1. 헤더: 종목명, 티커, 시장, 업종, 현재가/등락(지연 표기), 거래량 변화율
2. `오늘의 연결` — 뉴스별 카드. 각 카드에 미니 경로 + connection_type
3. `왜 발견됐나요?` — 선택 연결의 경로를 세로 스텝으로 (🌪️ 태풍 노루 → 🦌 노루 → 🏢 노루페인트)
4. `실제 사업 연관성` — 3단계 + **반증 근거** 표기
   - 예: "도료·페인트 제조. 최근 사업보고서상 기상·재해 관련 매출 항목 없음. (출처: DART 사업보고서 2025.03)"
5. `시장 반응` — 거래량 변화, 등락률, 5일 스파크라인 (캔들 아님)
6. `과거 유사 사례` (S 등급)
7. 고지 + **"투자 추천이 아닙니다"** 강조 박스

**규칙**: 시세는 항상 `기준 시각` 병기. 장중 실시간처럼 보이는 애니메이션 금지(오해 소지).

## S5. 발견 `/discovery`
- 익명 접근 가능, SSR + OG 이미지
- `오늘의 억지 관련주` 랭킹 10
- `이번 주 명예의 전당`
- 각 항목 공유 버튼 → `/api/og/connection/[id]` 이미지 + 딥링크
- 사용자 제보 입력창(S 등급, D2 준수): "키워드를 던지면 공개 피드에서 함께 탐색합니다" — 개인 1:1 응답 없음을 명시

## S6. 검색 `/search`
- 단일 입력 → 3탭 결과(뉴스 / 기업 / 키워드)
- 기업 검색은 티커·정식명·약칭·구 사명·영문명 모두 매칭
- 최근 검색어 로컬 저장(메모리/쿠키), 인기 검색어 서버 제공
- 검색 결과 0건: 유사 개체 제안("혹시 '노루페인트'?")

## S7. 알림 `/alerts`
- 키워드 등록(최대 무료 5개), 조건: `연결 강도 ≥ N`(기본 60), `밈 포함 여부`
- 발송 정책: 키워드당 일 3회 상한, 동일 클러스터 중복 발송 금지, 22:00~07:00 무음
- 페이로드: `🚨 "태풍" 뉴스 발생 · 연결 발견: 노루페인트 (NAME_MATCH 97)`
